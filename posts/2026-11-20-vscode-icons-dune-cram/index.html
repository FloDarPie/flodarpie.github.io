VSCode, vscode-icons et tests Cram

Nov 20, 2026

Avec dune, les tests cram s’écrivent dans des fichiers .t. Problème : l’extension vscode-icons ne les reconnaît pas et leur attribue l’icône par défaut. Voici comment leur associer une icône, intégrée ou personnalisée.

1. Associer une icône existante

vscode-icons se configure dans le settings.json utilisateur (Ctrl+Shift+P → Preferences: Open User Settings (JSON)), via la clé vsicons.associations.files :

  • icon : nom de l’icône sans le préfixe file_type_ ni l’extension. La liste complète se trouve dans le dossier de l’extension : ~/.vscode/extensions/vscode-icons-team.vscode-icons-<version>/icons/ (ex. file_type_dune.svg → dune, file_type_test.svg → test).
  • extensions : les extensions sans le point ("t", pas ".t").
  • format : svg ou png.

2. Utiliser sa propre icône

Si aucune icône ne convient, on peut fournir la sienne. vscode-icons cherche les icônes personnalisées dans le dossier vsicons-custom-icons, placé dans le répertoire utilisateur de VSCode :

OS Chemin
Linux ~/.config/Code/User/vsicons-custom-icons/
macOS ~/Library/Application Support/Code/User/vsicons-custom-icons/
Windows %APPDATA%\Code\User\vsicons-custom-icons\

Le chemin peut aussi être changé avec vsicons.customIconFolderPath.

Créer l’icône SVG (GIMP / Inkscape)

GIMP travaille en matriciel : il ne sait pas exporter une image en SVG. Seuls les chemins (paths) peuvent être exportés en SVG.

Depuis GIMP, exporter un chemin :

  1. Ouvrir la fenêtre Chemins : Fenêtres > Fenêtres ancrables > Chemins.
  2. Pas encore de chemin ? Faire une sélection, puis Sélection > Vers chemin.
  3. Clic droit sur le chemin → Exporter le chemin…
  4. Nommer le fichier file_type_test_dune.svg et choisir d’exporter le chemin actif ou tous les chemins.

Pour vectoriser une image matricielle, passer par Inkscape :

  1. Exporter l’image en PNG depuis GIMP.
  2. L’ouvrir dans Inkscape, puis Chemin > Vectoriser un objet matriciel (Shift+Alt+B).
  3. Fichier > Enregistrer sous au format SVG simple.

Conseil : utiliser une icône carrée, avec un viewBox="0 0 32 32", pour un rendu propre dans l’explorateur de VSCode.

3. Appliquer

Les modifications ne sont pas prises en compte à chaud : Ctrl+Shift+P → Icons: Apply Icons Customization, puis recharger la fenêtre (Developer: Reload Window).

Et voilà, les tests cram ont enfin leur propre icône dans l’explorateur.
